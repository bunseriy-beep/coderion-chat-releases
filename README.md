# QLinkChat — Релизы

Официальные установщики QLinkChat для Windows и Linux.

Скачивание доступно через страницу релизов: https://github.com/bunseriy-beep/qlinkchat-releases/releases

## Платформы

| Платформа | Формат |
|-----------|--------|
| Windows   | `.exe` (установщик), `.exe` (portable), `.msi` |
| Linux     | `.AppImage`, `.deb` |
